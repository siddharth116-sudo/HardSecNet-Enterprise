# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our Standards

- Be respectful and constructive in all interactions
- Focus feedback on the work, not the person
- Welcome contributors of all experience levels
- Security research should be conducted ethically and responsibly

## Enforcement

Violations may be reported to the project maintainer. All reports will be reviewed and addressed appropriately.
